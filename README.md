# Aplikasi Notes  
Aplikasi pencatat sederhana berbasis PyQt5 yang memungkinkan pengguna membuat, menyimpan, dan mengelola catatan dengan mudah. Setiap catatan dapat diberi tag untuk membantu pengelompokan dan pencarian.

Cara penggunaan:

1. Klik Create note untuk membuat catatan baru.
2. Pilih catatan dari daftar untuk melihat atau mengedit isinya.
3. Tulis atau ubah isi catatan pada area teks, lalu klik Save note untuk menyimpan.
4. Tambahkan tag dengan mengetik pada kolom tag lalu klik Add to note.
5. Hapus tag dengan memilih tag lalu klik Untag from note.
6. Gunakan Search notes by tag untuk mencari catatan berdasarkan tag tertentu.
7. Klik Delete note untuk menghapus catatan yang dipilih.

Aplikasi ini menyimpan data catatan dalam file JSON sehingga data tetap tersimpan meskipun aplikasi ditutup.
